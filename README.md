# Indira Nikunj Rubystone Exotic — Website V7

This version uses the uploaded transparent Rubystone logo throughout the site and adds a dedicated Weddings & Celebrations section with a "See More Images" gallery and full-screen image viewer.

## Included
- `index.html` — complete static homepage
- `style.css` — responsive luxury hotel styling
- `script.js` — mobile menu, gallery, lightbox and demo enquiry form
- `assets/rubystone-logo.png` — uploaded transparent logo
- `assets/wedding-01.jpg` ... `wedding-14.jpg` — supplied wedding/celebration images
- additional property, room, dining and view images

## Open locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Use Live Server, or double-click `index.html`.
4. For Netlify: drag the whole project folder (the folder containing `index.html`) into the Production deploy area.

## Important
The enquiry form is currently frontend-only. It does not store/send submissions until the Node.js + Express + MongoDB backend is connected.

Before client delivery, replace any placeholder social links and confirm all public-facing property details with the client.
